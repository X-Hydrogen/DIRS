# Scientific reproducibility and source-data provenance

## Required steps

From a clean environment use Python 3.11+, install with
  python -m pip install -e ".[test]"
then execute
  python scripts/reproduce_publication.py --verify-raw
and
  python -m pytest -q

The main command must terminate successfully and create the generated CSVs
and a reproduction_report.json with all_comparisons_passed=true.

## Input versus reference separation

- calculations/: source geometries, masses, Cartesian Hessians, local-coordinate
  definitions and ORCA input decks; this is the physical numerical input.
- reference/: the final immutable SI/manuscript comparison tables, never loaded
  as precomputed response values.
- reproduced/: computed outputs generated by a new invocation; not tracked.

The reproduction script recomputes the Cartesian rigid-invariance correction,
the mass-weighted vibrational eigenproblem, the coordinate-gradient projections,
compliance matrix, signed modal terms and normalized descriptors by re-executing
the original analysis implementation (analysis/stage3a_unified_response_analysis.py)
on the archived .npz records; it is a re-execution, not a second implementation.
With --verify-raw it parses the original ORCA .hess files and checks them against
the archived .npz. An implementation-independent recomputation from the raw .hess
text (three different routes to C_AB) is provided in scripts/independent_check.py
and exercised by tests/test_independent_crosschecks.py.

Executable status of the archived analysis scripts in this repository:
- stage3a_nine_system_reanalysis.py and revision_water_hexamer_prepare_endpoints.py
  run as archived (they write to analysis/*_outputs/ or a user-supplied path);
- revision_water_hexamer_dirs_analysis.py runs, but by default rewrites the archived
  compact .npz; pass --compact and --out pointing to a scratch directory;
- stage3b_method_robustness_analysis.py does not run: it calls
  calculations/benchmark_stage3/collect_orca_result.py, which is not archived, and
  would rewrite the archived compact records. Its endpoint values and gates are
  reproduced by scripts/reproduce_publication.py and
  tests/test_independent_crosschecks.py.

The numerical records were transferred from the project's frozen analysis
archive. The deposited `.hess`, `.npz`, XYZ, and coordinate-definition
files are sufficient for the response calculations; the separate research
archive is not required. The water-hexamer endpoint identities and
contact definitions are retained in
`calculations/revision_r1_water_hexamer_network/results/preregistered_endpoint_graph.json`.

## Calculation and numerical method

Production electronic-structure data:
- ORCA 6.1.1 PBE0-D4/def2-TZVPPD primary dataset, nine accepted systems.
- ORCA omegaB97X-D4/def2-TZVPPD alternative-functional control, five systems.
- ORCA 6.1.1 PBE0-D4/def2-TZVPPD water-hexamer network.

This is a functional comparison **at fixed basis**, not an independent
basis-set robustness test.

Cartesian Hessian K, diagonal mass matrix M and interatomic-distance
coordinate gradients b are converted into the mass-weighted rigid-free
vibrational operator H. The implementation enforces Cartesian
rigid-invariance before mass weighting, projects out five (linear) or
six (nonlinear) rigid modes and rejects nonpositive vibrational curvature.
Linearity is decided by a relative rotational singular-value threshold of
1e-8 (see Known limitations for the HCN dimer).

Static coordinate response is the corresponding off-diagonal compliance:
C_AB = chi_AB(0). Signed mode weights are w_s = c_As*c_Bs/omega_s^2.
The normalized net response is eta=chi_AB/sqrt(chi_AA*chi_BB),
absolute modal activity A=sum|w_s|/sqrt(chi_AA*chi_BB), and
kappa=|eta|/A. The distance-distance compliance conversion is
0.0642304854990309 angstrom/mdyn per a0^2/Eh.

Accepted frequency-analysis regions: [0, 200), [200, 1000) and
[1000, infinity) cm^-1 (lower bounds inclusive, as implemented).
They are analytical partitions, not universal molecular constants.
The original spectral-grid analysis code remains in analysis/.

## Published sets and exclusions

- Nine accepted primary systems, exactly 37 endpoint rows.
- Preregistered book-like water-hexamer network, exactly E1–E6.
- Five representative alternative-functional control systems,
  with published per-endpoint results.

The exploratory benzene-methane candidate failed positive-curvature
admissibility. The fluorobenzene-fluoroform candidate failed the
preregistered analytical-versus-numerical soft-curvature gate. Neither
is included as a positive accepted endpoint.

The water-hexamer raw ORCA frequencies (the unprojected
$vibrational_frequencies block of the deposited .hess; the ORCA .out file is
not archived) contain small signed translations/rotations because ORCA T/R
projection was disabled. Under the documented
rigid-free projection, all 48 vibrational modes are positive; the lowest
projected frequency is approximately 29.785779 cm^-1.

The scheme does not compute IVR kinetics or 2DIR/IR-THz experimental
intensities. Individual canonical modal terms may depend on the chosen
basis in near-degenerate subspaces; the complete signed response is
the invariant quantity within the harmonic model.

## Numerical gate and limitations

The fail-fast publication checker requires all reference endpoints to
be present, direct/modal closure <1e-8, and agreement with the frozen
published table. It uses rtol=2e-6 and atol=2e-8 for descriptors and
frequency partitions, and rtol=1e-8 / atol=1e-8 for compliance unit values.

The optional --verify-raw check independently parses the deposited
ORCA .hess files and compares Cartesian Hessian, masses and positions
to the archived .npz record with 5e-9 relative and absolute tolerance.

These checks establish numerical reproducibility for the specified
harmonic-response model. Cross-platform differences, especially those
involving near-degenerate modes, should be assessed against the reported
eigenvectors and integration conventions.

Reproducing the original DFT stage is optional, requires ORCA separately,
and may show normal platform/software precision differences.

## Known limitations

- **Basis dependence of A, kappa and band fractions.** chi_AB and eta are
  sums over modes and do not depend on how eigenvectors are chosen inside a
  degenerate subspace. A, kappa and the frequency-band fractions are built
  from |w_s| and do. For weakly coupled identical fragments (methane dimer)
  and the near-degenerate E-pair modes of ammonia-borane, the reported A
  and kappa refer to the canonical eigenbasis returned by the diagonalizer
  for the archived Hessian; small perturbations of the Hessian or masses can
  change them while leaving chi_AB and eta unchanged.
  scripts/independent_check.py reports an equal-frequency-cluster
  diagnostic envelope and an empirical sensitivity distribution under small
  symmetric Hessian noise. For finite gaps these are diagnostic envelopes rather than rigorous
  extrema of the original nondegenerate eigenproblem.
- **Frequency-band boundaries.** The [0, 200), [200, 1000) and
  [1000, infinity) cm^-1 fractions change discontinuously when a mode crosses
  a boundary. The chloride-water soft mode lies at 206.1 cm^-1 (PBE0-D4) and
  199.0 cm^-1 (omegaB97X-D4), so its fractions move between the low and mid
  bands between functionals. The functional-control gates do not test band
  fractions.
- **Linear HCN dimer.** The HCN dimer is linear to about 2e-6 angstrom, but
  the 1e-8 rotational threshold classifies it as nonlinear, so six rather
  than five rigid modes are projected out and one bending component is
  removed. Treating it as linear changes the published HCN endpoint values
  by at most 1.6e-8 (relative), because axial distances have no first-order
  bending component.
  The published values use the archived threshold; a strict xfail test in
  tests/test_independent_crosschecks.py records the behaviour. The
  1.6e-8 comparison concerns static response quantities, not a certified
  bound on all individual modal descriptors or spectrum partitions.
- **Electronic-structure provenance.** The archived ORCA .hess files contain
  the Hessian, geometry, masses and ORCA frequencies used by every analysis.
  The full ORCA standard-output files (SCF/optimization logs and final
  gradients) are not included in this repository.
- **Archived scripts.** stage3b_method_robustness_analysis.py and the
  default mode of revision_water_hexamer_dirs_analysis.py are retained as
  provenance (see above); use scripts/reproduce_publication.py to reproduce
  their published values.
