# Data package

The released primary dataset contains exactly nine accepted PBE0-D4/def2-TZVPPD systems and their frozen local-coordinate definitions. Each accepted sample supplies the raw ORCA Hessian, compact NPZ representation, optimized XYZ geometry, and ORCA input deck. The 37 published rows are reproduced with scripts/reproduce_publication.py, not read as the computational answer from reference tables.

The separate water-hexamer and omegaB97X-D4 data are documented in docs/REPRODUCIBILITY.md. Excluded exploratory candidates are not represented as accepted results.
